# MEWAY — проверенный пакет исправлений (15.10.2026)

## Изменения
- Word Vault: карточки и увеличенный просмотр отображают только текст, без изображений или заглушек; редактор не предлагает загрузку фото. В этой ветке сервер убирает image из слов при следующем сохранении коллекции. **Существующие записи D1 этим ZIP не изменены.**
- Quiz, challenges с вопросами, missions: сервер пересчитывает XP из проверенного транскрипта ответов, округляя `maxXp * correct / total` до целого. Повторное начисление за один и тот же материал предотвращено.
- Исправлено ограничение ID в `/api/xp/claim`: до 20 цифр, чтобы ID на основе Date.now()*1000 не получали ошибку 400.
- При XP claim сервер сначала запрашивает конкретный материал из D1 по ID, избегая полной параллельной загрузки всех разделов. Для встроенных и сгенерированных материалов сохранён резервный поиск.
- На экране результата миссии показан расчёт пропорциональных XP с пометкой о подтверждении сервером.

## Проверено

## Ограничения / перед Production
- Полный `npm run build` не выполнен: в среде нет всех зависимостей, `npm ci --offline` завершился ENOTCACHED.
- Реальная D1 и Discord OAuth не тестировались.
- Автоматическая пропорциональная оценка НЕ реализована для всех игровых форматов: crossword, puzzle, memory, drag-sort и некоторых других игр пока имеют собственные сценарии завершения без серверно проверяемого протокола каждого ответа. Для них не заявляется пропорциональная награда. Требуется отдельная доработка проверяющего API по типам игр.
- Задания без объективных ответов (отметить выполнено, изучение слов, письменная работа) не могут безопасно использовать долю правильных ответов; нужна ручная оценка или отдельная модель проверки.
- В текущем интерфейсе старые ошибочные XP claims остаются в локальной очереди до успешного подтверждения/отдельной обработки. Не очищать IndexedDB без экспорта очереди.
- Перед выкладкой сделать резервную копию D1, проверить сборку и тестовую среду.
