# MEWAY — перемешивание и Drag & Sort

- В редакторе игр есть галочка «Перемешивать слова / игровые карточки для ученика» (`payload.shuffleWords`). По умолчанию выключена для совместимости.
- Drag & Sort: при включении перемешиваются доступные слова один раз при открытии игры. Перемещённое слово исчезает из банка; можно вернуть его нажатием или перенести в другую зону.
- Для остальных карточных игр при включении меняется порядок карточек при открытии. Для `odd-one` порядок карточек намеренно не меняется: эта механика может зависеть от заданного правильного ответа.
- Перемешивание локальное, без дополнительных запросов Worker/D1/KV. Публикация настроек использует существующий механизм сохранения.
