# MEWAY: локальный Ассистент и Local First XP

Основа: MEWAY-LOCAL-FIRST-XP-SOURCE. IndexedDB + D1 + KV и существующая очередь XP сохранены без изменений.

## Изменения
- Открытие Ассистента не выполняет `/api/assistant/bootstrap`.
- Вопросы, подсказки, навигация, локальная база знаний и история чата работают без HTTP-запросов.
- Неизвестные вопросы сохраняются только локально, `/api/assistant/escalate` автоматически не вызывается.
- Сообщение в поддержку по-прежнему отправляется на `/api/assistant/support`.
- Добавлена явная кнопка «Обновить ответы поддержки», которая по нажатию загружает ответы администратора и опубликованную базу знаний.
- Административные публикации и ответы по-прежнему отправляются на сервер только при явном действии.

## Ограничения
- Ответ администратора не появится автоматически без явного обновления или другого серверного события.
- Новые опубликованные сценарии становятся доступны на устройстве после нажатия кнопки обновления.
- Полная TypeScript/Vite-сборка и интеграционные проверки Discord/D1/KV требуют зависимостей и сервисов.
- Серверная защита XP для всех типов игровых активностей не завершена в исходной базовой версии.
