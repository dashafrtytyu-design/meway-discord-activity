# MEWAY 7.31.26 — безопасное обновление действующей версии

Основа: сохранённый проект 7.31.25, который ранее был опубликован вместе с 600 новыми заданиями. Присланный 29 октября ZIP с `package.json` версии 7.31.24 был старее опубликованного проекта; поэтому полный откат к нему не выполнялся.

## Изменения

1. Админка: редактирование и создание миссий, квизов, словарей, челленджей и наград — отдельные поля «Направление» (Разговорный / Бизнес / Политика / Литературный) и «Тема». Назначения сохраняются в `track` и `topic` в D1. Поля применяются и к старым записям при редактировании. У игр новых направлений нет, игровая логика не менялась.
2. Ассистент: удалены вкладка, клиентская страница, локальная FAQ-база, серверные маршруты, экран в UI Studio и CSS. Устаревшие локальные ключи ассистента очищаются при первом запуске. Старые таблицы в живой D1 **не удаляются автоматически**, чтобы не терять данные без подтверждённого резервного копирования; для владельца приложен отдельный ручной SQL.
3. Учебный путь: каталог игр получаем коротким D1-запросом к ID/уровню/статусу, без игровых payload. Серверный кэш каталога сбрасывается при изменении ревизий; клиент однократно запрашивает каталог, если данных об играх вообще нет. Автообновление текущего администратора происходит после сохранения/удаления материала. Прогресс остаётся на основе ID из текущего опубликованного каталога и подтверждений сервера. Уровень завершается только при выполнении всех пяти разделов.
4. Активность: исправлено локальное вычисление Streak без UTC-сдвигов; клиент больше не объявляет день посещённым до серверного подтверждения. Исторические неподтверждённые дни до периода надёжного учёта оставлены серыми.
5. Главная: Daily Goal теперь использует правильную выбранную метрику (ответы / миссии / материалы); число повторений не генерируется приблизительной формулой, а берётся из реальной локальной очереди. Плитка «Недавние» называется «Недавние разделы»; переход «Продолжить» не отправляет пользователя по несуществующему маршруту.
6. В тёмной и голубой темах добавлены явные контрастные цвета для полей редактора/выбора направления. Остальная цветовая система сохранена.
7. Старые исправления XP и мобильная верхняя панель Discord из 7.31.25 сохранены. В D1 не было никаких изменений на этапе разработки этого ZIP.

## Перенос в существующий Codespaces

**Не копируйте 7.31.24 поверх 7.31.25.** Для работающей 7.31.25 используйте `MEWAY_7.31.26_UPDATE.patch` из архива с изменениями.

1. В Codespaces откройте `meway-discord-activity`. Сохраните незакоммиченные локальные изменения: `git status --short`, экспортируйте нужные изменения отдельно. Не загружайте архив/резервную копию D1 в публичный GitHub.
2. Загрузите `MEWAY_7.31.26_UPDATE.patch` в корень проекта рядом с `package.json`.
3. Выполните `git apply --check "MEWAY_7.31.26_UPDATE.patch"`. Если появились конфликты, **не применяйте принудительно**, сперва их нужно объединить. Если проверка прошла: `git apply "MEWAY_7.31.26_UPDATE.patch"`.
4. `npm ci` (если зависимости отсутствуют), затем `node --test tests/*.test.mjs`, затем `npm run build`.
5. До деплоя: проверить админские поля на черновике, выбрать тёмную/голубую тему, убедиться, что все 990 игр и 600 новых материалов присутствуют в D1. Для проверки D1 доступен `qa/D1_TOTALS_READ_ONLY.sql`; он не меняет данные.
6. Если сборка и проверки успешны, `npx wrangler deploy`. **Никакой SQL-пакет ADD_*.sql повторно не запускать:** 600 материалов уже импортированы на предыдущем шаге. Команда deploy публикует Worker и `dist`, не очищая D1.
7. В Discord проверить 5 карточек маршрута на A1 и C2; завершить одну ещё не пройденную игру и удостовериться, что подтверждение XP, `completedContent` и проценты остались после перезахода. В админке создать черновик с направлением «Политика» и темой, сохранить и снова открыть его. Проверить неподготовленные уровни без доступа, календарь и главную на телефоне. Только после этого — `git status --short`, выборочное `git add` исходников, `git commit`, `git push`.

## Не включено в автоматическую публикацию

- Старые сообщения ассистента в Cloudflare D1. Для **необратимого** удаления после новой резервной копии существует `optional_sql/REMOVE_ASSISTANT_HISTORY_ONLY_AFTER_BACKUP.sql`. Не выполняйте этот SQL ради обычного обновления. При откате Worker на старую версию таблицы могут быть созданы снова.
- Исправление незарегистрированных устаревших XP-заявок (например, ID задания, отсутствующего в D1): сохраняется существующая очередь, но 404 за удалённое задание не превращается автоматически в начисление.
- Гарантия полной визуальной проверки каждой кнопки: это требует настоящего входа через Discord и реального устройства.

**Важное различие:** SQL D1 показывает только записи, хранящиеся в D1. Итоговый пользовательский каталог также может включать встроенные материалы и исключать удалённые/архивные. Поэтому сравнивайте итоговые числа с `/api/learning-catalog`, а не только с SQL-таблицами.
