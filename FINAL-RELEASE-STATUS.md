# MEWAY — проверка релиз-кандидата (11.10.2026)

## Исправление этой версии
В `src/App.tsx` устранена ошибка выбора HTTP-метода сохранения: новые материалы получают стабильный ID ещё в редакторе, поэтому проверка `x.id` всегда выбирала PUT. Теперь метод определяется по наличию материала в загруженном списке: новые — POST `/api/admin/content`, существующие — PUT `/api/admin/content/:id`. Серверный POST сохраняет переданный ID и не перезаписывает материал при повторе.

## Безопасная публикация
1. Сохраните прежний ZIP, резервную копию D1 и текущие Cloudflare bindings/секреты. Не создавайте пустую D1 взамен рабочей.
2. Замените только исходники репозитория. Не удаляйте D1/KV и не выполняйте разрушительных SQL-команд.
3. В Cloudflare CI выполните `npm ci`, `npm run build`, `npm run lint`, `node --test tests/*.test.mjs`. При любой ошибке остановите публикацию.
4. На тестовом администраторе создайте черновик, опубликуйте карточку с прозрачным PNG, обновите страницу, измените текст, удалите тестовую карточку. Проверьте Network и появление у тестового ученика.
5. Проверьте начисление XP, вход со второго устройства, доступы A1–C2 и роли Discord; только затем переключайте пользователей на новую сборку.

## Ограничения
Нельзя честно утверждать, что все кнопки, серверные API, мобильная адаптивность, XP и роли проверены end-to-end. Текущая сборка — релиз-кандидат с подтверждёнными автоматическими тестами, но не подтверждённая production-сборка.
