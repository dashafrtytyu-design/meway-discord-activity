# MEWAY — проверка редакторов

Изменено: обновления полей и карточек через функциональные обновления React, чтобы позднее завершение обработки изображения не перезаписало новые изменения; отдельные контейнеры полей вместо вложенных label; уменьшен риск совпадения ID быстро добавленных вопросов.

Сохранены существующие данные, XP, D1, Discord, стили и игровые механики. Дополнительных сетевых запросов не добавлено.

Проверки `node --test tests/*.test.mjs` и `npm run build` выполняются по возможности. Статические тесты не являются доказательством работы всех кнопок на реальном Discord/Cloudflare.
