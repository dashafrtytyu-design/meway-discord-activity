MEWAY V7.6.5 — CLOUD SAVER / EVENT-ONLY ROLE SYNC

- Removed 15-minute Discord role verification completely.
- Removed Discord role lookup from GET /api/progress.
- Removed 15-minute lastSeen D1 checkpoint.
- GET /api/progress writes D1 only on first visit, first activity of a new day, or Discord identity change.
- Discord role synchronization runs only when the XP level changes, plus one initialization sync for legacy rows without syncedRoleId.
- Level-crossing progress saves remain urgent in the frontend, so the role is granted immediately rather than waiting for the normal 20-second batch.
- Normal progress changes remain batched for 20 seconds, reducing Worker/D1 usage.
- Existing UI, content, levels, MASTER ZONE, admin, streak, leaderboard and Motion UI are preserved.
