# MEWAY — исправления игр (13.10.2026)

- Вопросы миссий и квизов: единая нормализация ответов, поддержка старого формата правильного варианта как индекса, подсветка на основании той же проверки.
- Игры с отдельной механикой (Memory Cards, Sentence Order, Translation Input, Missing Word, Word Builder) больше не заменяются обычным тестом при наличии вариантов ответов.
- Memory Cards: редактор пар русский/английский; ученик сопоставляет карточки.
- Sentence Order: редактор готового предложения; у ученика слова перемешаны, повторяющиеся слова имеют отдельные идентификаторы.
- Translation Input: русское слово/задание и скрытый английский ответ, локальная проверка без отдельного запроса, ошибка показывает ответ.
- Speed English, True/False, Categories: специальные поля редактирования. True/False использует явно заданный ответ, а не ненадёжную эвристику.
- Фото-пазл: кнопка «Завершить и проверить», неверно расположенные фрагменты отмечаются красным; XP-колбэк только при верной сборке.
- Админ-панель игр: кнопка «Проверить игру глазами ученика» запускает настоящую механику ученика без XP и серверных запросов.
- XP в обычной серии раундов не запрашивается, если хотя бы один раунд был неверным. Серверная проверка XP остаётся обязательной.

## Безопасное обновление

Сделайте резервную копию D1 и GitHub-репозитория. Замените исходники в GitHub файлами архива. Не удаляйте и не пересоздавайте D1/KV и секреты. В Cloudflare выполните `npm ci` и `npm run build`, выходная папка `dist`. После развёртывания проверьте один черновик каждой игры в режиме ученика и одну тестовую публикацию. Не публикуйте миграции: для этих правок они не нужны.
