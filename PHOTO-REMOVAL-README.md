# Удаление фотографий карточек MEWAY

В админ-панели в редакторе слов у каждой карточки есть кнопка «Удалить фото». Она удаляет ссылку/встроенное изображение только из текущей карточки, не меняя слово и остальные поля. После подтверждения устанавливается `image: ''` и `imageDisabled: true`, чтобы на уровне A1 не подставлялась автоматическая иллюстрация. Новая загрузка фото устанавливает `imageDisabled: false`.

Изменения сохраняются в D1 только после «Сохранить и применить» и успешного ответа сервера. Существующие записи D1 не меняются при загрузке ZIP. При серверной ошибке не считайте удаление подтверждённым.

Для надёжности до массового редактирования сделайте резервную копию D1 и проверьте одну карточку: удалить фото → сохранить → открыть с другого устройства → проверить отсутствие фото → загрузить обратно → сохранить → повторно открыть.

Проверки: локальные 53 автоматических теста прошли. Живая D1/Discord и production build здесь не проверены. Текущий механизм истории версий не заменяет отдельную резервную копию D1.
