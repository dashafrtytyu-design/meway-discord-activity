## Ограничения и следующие действия
- Причина реального отказа сохранения на сервере не установлена без HTTP-статуса/ответа и Cloudflare Worker logs.
- Большие наборы фотографий в одном материале могут всё ещё превышать пределы D1; оптимальное долговременное решение — отдельное объектное хранилище с согласованной конфигурацией, без удаления старых data URL.
- Перед публикацией сохранить резервную копию D1; не удалять существующую базу и привязки.
- Опубликовать Worker и frontend вместе; проверить создание, редактирование и просмотр карточки в ученическом аккаунте.
- Если ошибка остаётся, записать Request URL, Status и Response из DevTools Network для POST/PUT /api/admin/content.
