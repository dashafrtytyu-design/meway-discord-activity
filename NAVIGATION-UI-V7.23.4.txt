MEWAY V7.23.4 — Navigation Active State + Smart Swipe Hint

- Removed the incomplete white active-navigation outline on touch/mobile UI.
- Active destination now uses a theme-aware icon glow, subtle lift and animated underline.
- Keyboard accessibility is preserved with :focus-visible only; touch focus does not show the old white outline.
- Light and dark themes have separate active-state contrast.
- Added a Home-page swipe hint only when the actual navigation element overflows horizontally.
- Overflow is detected dynamically using scrollWidth/clientWidth + ResizeObserver, so the hint reacts to viewport/orientation/layout changes instead of assuming a device type.
- The hint is hidden on wide desktop layouts and is not rendered when all destinations fit.
- Respects MEWAY reduced-motion setting and prefers-reduced-motion.
- No API, Worker, D1, XP, access, Placement Test, content, admin or storage behavior was changed.
- Adds zero Cloud/D1 requests.
