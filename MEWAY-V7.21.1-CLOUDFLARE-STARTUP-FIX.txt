MEWAY V7.21.1 — Cloudflare Worker startup fix

Cause from Cloudflare deployment log:
- frontend production build succeeded;
- Worker validation failed with code 10021 because startup CPU exceeded the 1-second Worker startup limit.

Fix:
- worker.ts no longer imports contentSeed.ts at module startup;
- the large generated curriculum is served as static assets already present in public/curriculum-content.json and public/curriculum-missions.json;
- Worker loads those JSON datasets lazily only when the corresponding API data is requested and caches them in the warm isolate;
- generated built-in deletion/tombstone semantics are preserved by consulting the lazily loaded datasets on DELETE;
- starter content, D1 overrides, revisions, admin access, Discord role sync, XP logic and static frontend assets remain in place.

This specifically removes the large curriculum generation/evaluation from Worker module initialization, which is the startup path Cloudflare rejected.
