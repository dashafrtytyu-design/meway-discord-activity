# MEWAY: локальная загрузка админ-материалов

- Для ранее открытых разделов админки используется зашифрованный IndexedDB-кеш, разделённый по Discord User ID. Кеш не привязан к номеру сборки интерфейса.
- Кешированные разделы не делают fetch при обычном переключении вкладок. Для первого открытия отсутствующего в кеше раздела выполняется один запрос к Worker; постраничная загрузка выполняется только по кнопке.
- Добавлена ручная кнопка «Обновить с сервера», чтобы получать подтверждённые изменения и удаления, выполненные на другом устройстве. Кеш не считается авторитетным при сохранении или проверке прав.
- У загрузок есть тайм-аут 20 секунд; при сбое ранее загруженные данные не стираются.
- Успешное сохранение/удаление сбрасывает соответствующий локальный кеш; изменения подтверждаются Worker и D1, а не одним IndexedDB.
- Нового polling нет. Рабочая D1 не менялась.

## Важные ограничения

Это не полная offline-first реализация черновиков для всех редакторов. У отдельных редакторов локальные черновики могут не сохраняться между перезапусками браузера. История изменений и подтверждение D1 требуют реального Worker. Кеш может быть устаревшим после действий другого администратора: используйте ручное обновление. Не очищайте IndexedDB до проверки серверных резервных копий.
