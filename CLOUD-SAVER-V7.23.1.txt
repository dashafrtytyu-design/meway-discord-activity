MEWAY V7.23.1 MAX CLOUD SAVER

Optimizations applied without changing UI/content structure:
- Startup auth response already bundles course access, revisions and progress.
- Placement-completed flag is now bundled into that same auth response, removing a separate placement-config request from every app launch.
- Placement Test configuration is fetched only when Placement Test is actually opened.
- Placement variant selection no longer scans full placement_history. It reads only placement_results for the last counted attempt.
- Placement submission eligibility also reads only placement_results; full audit history remains append-only for Admin.
- Placement audit + latest result writes use one D1 batch when a retake is eligible.
- Placement config uses warm-isolate public cache and is invalidated immediately after admin saves changes.
- Curriculum remains persistent encrypted IndexedDB/local cache with revision delta sync.
- No polling/timers for curriculum, progress, roles, leaderboard or admin.
- Ordinary answers remain local-only; cloud progress writes occur on durable milestones only.
- Discord XP role sync remains event-driven (level crossing) with bounded recovery retry.
- Leaderboard remains session cached.
- Admin bootstrap/students/sections remain session cached and only load when needed.
- Static visual dictionary/UI assets remain local; no external image host is required for generated vocabulary visuals.

Intentionally NOT reduced further:
- Auth: required to establish Discord identity and permissions.
- Durable XP/completion saves: required to avoid losing real progress.
- Placement submit: required for audit/result integrity.
- Admin saves: required to persist edits.
- Role sync on XP-level crossing: required to keep real Discord roles reliable.

Build note:
The supplied archive does not contain installed node_modules in this runtime. npm run build cannot resolve vite/client and @types/node until dependencies are installed. Source-level changes are present; do not interpret this note as a successful production build.
