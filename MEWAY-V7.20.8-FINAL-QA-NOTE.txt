MEWAY V7.20.8 — publication QA note

Implemented:
- Existing V7.20.7 architecture/content preserved.
- Global English-entry deduplication remains enabled.
- Every rendered dictionary entry now receives a deterministic unique transparent SVG composition based on the exact English entry + Russian text + category.
- No emoji and no external image/CDN request is used for the automatic dictionary visual.
- Admin-uploaded custom artwork still takes priority.

Important lexicographic limitation:
This build is NOT labelled "zero-error lexicographically certified". The inherited IPA table contains machine-generated British-style IPA and was not individually checked entry-by-entry against a licensed authoritative pronunciation dataset. A zero-error claim would therefore be false. Oxford/Cambridge/EVP can be used as verification references, but their full dictionary datasets were not copied into this build.

Publication recommendation:
Technical UI/image generation can be tested now. Before describing the dictionary publicly as fully lexicographically verified, perform entry-level editorial review of IPA, Russian sense, POS/CEFR and example for every published entry.
