# MEWAY — диагностика загрузки слов из D1

Изменён `src/App.tsx`: загрузчик показывает HTTP-статус ошибки `/api/content` или `/api/sync`, не заменяет подтверждённый кеш демонстрационными карточками и сохраняет последнюю успешную копию IndexedDB при сбое синхронизации. Постоянных дополнительных запросов нет.

## Проверка после публикации

1. Сохраните резервную копию рабочей D1 и предыдущий коммит GitHub. Не удаляйте базу.
2. Проверьте Cloudflare Worker → Settings → Bindings: переменная `DB` должна ссылаться на прежнюю D1 с материалами.
3. В Discord полностью закройте Activity и откройте её заново. Перейдите в «Слова» и нажмите «Повторить загрузку» при ошибке.
4. Если отображается `401`, проверьте Discord OAuth, `DISCORD_CLIENT_SECRET` и повторную авторизацию. При `403` проверьте серверные права. При `500` проверьте Worker Logs и D1 binding.
5. В Cloudflare D1 Console выполните только чтение: `SELECT id, section, updated_at FROM content WHERE section = 'words' ORDER BY updated_at DESC LIMIT 30;`.
6. Если записи существуют, не создавайте их заново: исправьте авторизацию/привязку D1. Если их нет, проверьте резервные копии и не импортируйте поверх рабочей базы без отдельного плана.

## Ограничения

Доступа к опубликованному Worker и рабочей D1 нет. Причина фактического HTTP-сбоя и наличие старых карточек на сервере пока не подтверждены. Тесты Node не являются тестами Cloudflare D1. Production build в этой среде не выполнен: `npm ci --offline` не нашёл пакет `zod` в локальном кеше.
