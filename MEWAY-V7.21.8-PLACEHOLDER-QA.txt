MEWAY V7.21.8 — GLOBAL EMPTY EDITOR PLACEHOLDERS

Scope: Admin visual editor and detailed editor creation flows.

Fixed:
- Adding a new answer option in LIVE student-view editor now appends an empty string. "Вариант N" is a placeholder only.
- Removed the generic-game editor fallback that manufactured "Правильный ответ" / "Другой вариант" as real values.
- New top-level missions/materials no longer start with real textual values such as "Новая миссия", "Новый материал", default category text, icon text, or duration text.
- Added placeholders to common detailed-editor fields (title, icon, duration, description, dictionary word fields, synonyms, antonyms).
- Existing saved/published content is not erased or converted; only newly-created editor values are affected.
- No audience/children/adults feature was added.
- Placeholder behavior is local UI state and adds no Cloudflare/D1 request.
