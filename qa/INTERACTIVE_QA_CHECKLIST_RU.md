# Контрольный список MEWAY 7.31.26 перед окончательной публикацией

Отмечайте на действующем Discord Activity, с тестовым учеником и тестовым администратором.

## Пользовательские маршруты

- [ ] Авторизация через Discord, повторный вход с тем же XP.
- [ ] Переключение A1–C2: доступные уровни открываются, заблокированные нет.
- [ ] Четыре направления и их темы: сначала направление, затем тема.
- [ ] Игры имеют только прежние уровни и типы — без четырёх направлений.
- [ ] Карточки маршрута показывают пять разделов, включая реальные игры.
- [ ] Уровень не закрывается при 4 из 5 завершённых разделов.
- [ ] Новая опубликованная миссия увеличивает знаменатель и уменьшает процент на следующем обновлении каталога.
- [ ] Черновики и архивы не попадают в учебный путь.
- [ ] Завершение одной новой игры меняет count после ответа сервера, результат сохраняется при следующем входе.
- [ ] Финал уровня предлагает открыть следующий доступный уровень либо объясняет получение доступа.

## Админка

- [ ] Создать и редактировать миссию — направление, тема, уровень, XP, длительность.
- [ ] Создать и редактировать квиз — направление, тема, объяснения, XP.
- [ ] Создать и редактировать челлендж — направление, тема, XP.
- [ ] Создать и редактировать словарь — направление, тема, слова и транскрипция.
- [ ] Создать и редактировать награду — направление и тема (если используется как материал).
- [ ] Игры: существующие типы, уровни и редактор неизменны.
- [ ] После сохранения обновляется версия каталога; у ученика новый материал появляется при обновлении или входе.
- [ ] Ошибка сохранения не выводит успешное сообщение; проверка прав администратора работает.

## Главная, календарь, темы

- [ ] Daily Goal показывает фактическую метрику и заданную дневную цель.
- [ ] Повторения показывают только реальную очередь, не придуманные значения.
- [ ] Streak на границе суток и месяцев считает местные календарные дни.
- [ ] Серый день: до надёжного подтверждения; красный: подтверждённо пропущен после начала учёта.
- [ ] Навигация календаря по месяцам/годам с активностью.
- [ ] Светлая, тёмная, голубая темы: читаемые плашки, поля ввода, кнопки и меню.
- [ ] Телефонный Discord Activity: над системной шапкой видны XP, доступ, аватарка.
- [ ] Ассистент отсутствует в боковом меню, UI Studio и приложении, старые маршруты API недоступны.
- [ ] Ошибки сети, пустые разделы, повторное открытие и возврат из игры не вызывают бесконечную загрузку.
