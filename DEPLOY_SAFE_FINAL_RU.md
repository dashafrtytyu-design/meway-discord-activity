# MEWAY — финальное уточнение (1 ноября 2026)

Эта версия объединяет ранние исправления публикации, ускорения админки, доступа A1–C2 и регистрации учеников со следующими точными требованиями:

1. Белыми сделаны **только** надписи внутри синей всплывающей карточки `.levelUpToast` о новом XP-уровне. Цвета текста во всех остальных разделах, включая светлую и голубую темы, не менялись этим уточнением.
2. Все уровни A1, A2, B1, B2, C1, C2 можно выбирать в фильтре и видеть карточки материалов. Закрытая карточка показывает название/уровень и сообщение «Доступ закрыт — приобрети доступ», но при нажатии не открывается.
3. В ответе Worker на материалы закрытого уровня отсутствуют сами задания, ответы и содержимое игрового payload. Уровни открываются только через существующий механизм разрешений D1.
4. Код выдачи доступа ученику, XP и пропорционального начисления, проверки ответов, Placement Test, Discord API для MASTER ZONE **не менялся в финальном уточнении**.
5. В объединённой версии сохранились ускорение админки, постраничный список материалов и учеников, проверка записи в D1 и повышение надёжности синхронизации.

ПРОВЕРЕНО: `node --test tests/*.test.mjs` — 122/122.
НЕ ПРОВЕРЕНО: `npm run build` (в локальной среде недоступны зависимости tsc/Vite); соединение с опубликованным Cloudflare Worker и реальная выдача ролей. Перед `npx wrangler deploy` обязательны `npm ci`, `npm run test:all`, `npm run build` в Codespaces.

## Безопасная публикация — не удаляя данные

1. В Codespaces открой терминал репозитория `/workspaces/meway-discord-activity` и проверь `git status --short`. Не затирай незакоммиченные изменения: сначала сохрани их.
2. Сделай быстрое облачное подтверждение точки восстановления D1 (не меняет данные):

   `npx wrangler d1 time-travel info meway-content`

   Сохрани выведенный bookmark отдельно. Для Free-плана Time Travel обычно хранит историю **7 дней**, для Paid — до 30 дней. Встроенная функция доступна только на D1 production storage.

3. Для независимой долговременной копии выполни (экспорт временно блокирует другие обращения к D1):

   `npx wrangler d1 export meway-content --remote --output=../meway-content-backup-2026-11-01.sql`

   После завершения скачай SQL-файл себе и не загружай его в публичный репозиторий.

4. Создай отдельную git-ветку или коммит текущего кода, затем распакуй архив `MEWAY_FINAL_20261101_only_changes.zip` **в корне** репозитория (ZIP содержит пути `src/...`, `worker.ts`, `tests/...`). Используй `unzip -o АРХИВ.zip` только после проверки предыдущего шага.
5. Запусти:

   `npm ci`
   `npm run test:all`
   `npm run build`

   Если возникнет ошибка, НЕ разворачивай обновление. Исправляем причину отдельно.
6. Только затем выполняй `npx wrangler deploy` **в уже существующий Worker**. Убедись, что в `wrangler.jsonc` имя Worker и binding D1 `DB` указывают на прежнюю базу `meway-content` — НЕ создавай новую базу и НЕ выполняй SQL-импорт.
7. Проверяй игру, миссию, редактирование, доступы A1–C2, 0-XP пользователя, админский список XP, MASTER ZONE и поздравление. Для проверки роль MASTER ZONE не нужно менять XP реальных учеников — используй добавленную диагностическую кнопку в админке.

Кнопка «Вся база» в Discord Activity у тебя не скачивает файл, поэтому полагаться на неё нельзя. Причина конкретно этой ошибки пока не подтверждена. Time Travel и независимый SQL-экспорт — штатные альтернативы.

Нельзя гарантировать отсутствие каких-либо ошибок до проверки на живой публикации. При необходимости rollback делается на прежний Git-коммит и повторным деплоем; это **не** должно заменять D1. Восстановление самой D1 требует отдельного решения и может перезаписать новые данные — не выполнять автоматически.
