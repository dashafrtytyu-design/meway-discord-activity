# MEWAY — проверка публикации контента и выдачи MASTER ZONE
Дата: 1 ноября 2026 г. База анализа: пользовательский ZIP `meway-discord-activity-main (3)(3).zip` (версия 7.31.26).

## Цель
Чтобы новые материалы и изменения игр, квизов, слов, челленджей, наград и миссий сохранялись в Cloudflare D1 и становились видны ученикам; чтобы самостоятельная выдача Discord XP-ролей через Cloudflare, включая MASTER ZONE (10 000 XP), сохранялась без запущенного Python-бота.

## Подтверждено анализом исходного кода
- Обработка XP и ролей находится в `worker.ts`; функция `syncDiscordLevelRole` использует REST API Discord с токеном Cloudflare Worker, а не процесс Python на стороннем хостинге.
- `MASTER ZONE` на 10 000 XP имеет ID `1555241516363030568`.
- Начисления XP, Placement Test, данные учащихся, `wrangler.jsonc`, настройки D1 и Discord-токены НЕ изменены этой исправленной версией.
- По скриншоту админ-панель показывает игры со статусом «Опубликовано», однако без доступа к удалённой D1 нельзя подтвердить, что конкретная НОВАЯ игра записалась в настоящую базу.

## Найденные причины возможного «не добавилось»
1. Раньше серверные кэши списка материалов и ответов `/api/content` жили до 10 минут независимо от версии каталога. Другой Worker мог вернуть старые материалы после успешной публикации. В этой версии кэши учитывают ревизию D1, а чтение актуальной ревизии выполняется по запросу списка (не фоновым опросом).
2. Клиентский кэш мог показывать старый список, пока пользователь не переоткроет Activity. В учебных разделах появилась ручная кнопка «↻ Обновить материалы»; лишних постоянных запросов нет.
3. Максимальный размер строки D1 — 2 000 000 байт. Старая проверка Worker допускала до 12 МБ. Теперь сервер и клиент заранее показывают понятную ошибку при превышении 1 900 000 байт (запас для хранения), что особенно важно для игр с несколькими фото.
4. Загрузка старого списка материалов в админке могла завершиться уже после сохранения и перезаписать новый список на экране. Добавлена защита от запоздалых результатов, при успехе сбрасываются прежние кэши.
5. Изменение ревизий разных разделов раньше могло перезаписать чужую ревизию при одновременных публикациях из разных Worker. Обновление отдельного поля ревизии сделано атомарным SQL `json_set`.

## Как проверить MASTER ZONE без выдачи пробной роли
В админке открой «⚙️ Автоматизация» и нажми «Проверить выдачу MASTER ZONE». Новая администраторская проверка выполняет только GET-запросы Discord и показывает:
- действителен ли токен бота в опубликованном Cloudflare Worker;
- находится ли бот на нужном Discord-сервере;
- есть ли роль MASTER ZONE;
- имеет ли бот `Manage Roles` и находится ли его самая высокая роль выше MASTER ZONE.

Проверка НЕ меняет XP и НЕ выдаёт/удаляет роли. Успешный результат означает, что необходимые настройки присутствуют; он НЕ заменяет реальный тест выдачи роли при достижении 10 000 XP.

## Тесты
- 104 существующих теста проекта — успешно.
- 5 новых интеграционных тестов с изолированными имитациями Worker, D1 и Discord: создание и правка игры между изолятами, ограничение 2 МБ, проверка роли, публикация черновика и отсутствие токена — успешно.
- Исходники `worker.ts` и `src/App.tsx` синтаксически обработаны компилятором TypeScript без ошибок синтаксиса.
- SQLite-синтаксис атомарного обновления ревизий проверен на тестовой SQLite.
- `npm run build` в этой среде не завершён: при установке зависимостей нет сетевого доступа к части пакетов; отсутствуют `vite/client` и `@types/node`. В Codespaces нужно выполнить `npm ci`, `npm run test:all`, `npm run build` ДО деплоя.
- Настоящая D1, секреты опубликованного Worker, настоящий Discord API и работающая веб-страница в этом окружении не тестировались. Не делаем заявления о 100% гарантии.

## Безопасный план публикации
1. Оставь текущую рабочую версию опубликованного MEWAY без изменений, пока не сделаешь резервную копию D1. Не импортируй старую базу вместо актуальной.
2. Открой Админ → «Резервные копии MEWAY» → «Вся база» и скачай JSON. Дополнительно рекомендуется удалённый SQL-экспорт D1 через Wrangler (`npx wrangler d1 export meway-content --remote --output=meway-backup-20261101.sql`). Сохрани файлы вне рабочего репозитория.
3. Перенеси в существующий GitHub Codespace **только** `worker.ts`, `src/App.tsx`, `tests/worker-content-live-contract.test.mjs` (а также этот отчёт по желанию). Не меняй файлы с контентом, схемы D1 или секреты.
4. В корне репозитория: `npm ci`, затем `npm run test:all`, затем `npm run build`. Если сборка не проходит, НЕ публикуй.
5. Только после успешной сборки сделай обычное обновление прежнего Worker (`npx wrangler deploy`) с тем же `wrangler.jsonc` и существующей D1. Никаких очисток, удалений и массового импорта.
6. Открой Админ → «⚙️ Автоматизация» → «Проверить выдачу MASTER ZONE»; исправляй права только при наличии указанной ошибки. Никому не показывай токен.
7. Для проверки публикации создай НОВУЮ маленькую тестовую игру со статусом «Опубликовано», сохрани, открой Игры и нажми «↻ Обновить материалы». Проверь название, уровень, сам игровой процесс. Затем измени название, повтори проверку. Снимать/удалять настоящие игры и учеников не требуется.
8. При нестабильном результате до повторной публикации проверь уведомление админа и логи Cloudflare. Не повторяй публикацию наугад при таймауте: `/api/admin/content/:id/verify` проверяет запись в D1.

## Что НЕ трогать
Не трогать `DISCORD_BOT_TOKEN`, Discord application ID, порядок/ID шести XP-ролей, Placement Test, D1 XP и прогресс, `course_access`, контентные SQL-файлы, `src/xpOutbox.ts`, `src/xpQueueRunner.ts`, опции Cloudflare KV. Отдельный Python-бот для роли MASTER ZONE не требуется, но его Discord-учётная запись и действующий токен в Worker требуются.

## Дополнительные ограничения
- При статусе «Черновик» материал сохраняется для админа, но не виден ученикам. При статусе «Опубликовано» видимость также зависит от учебных фильтров и уровня доступа ученика.
- Cloudflare D1 объявил ограничение 50 МБ на результат одного запроса, вступающее в силу 4 ноября 2026 г. Если каталоги с фотографиями станут очень большими, понадобится отдельная оптимизация объёма ответов и пагинация. Текущий патч не меняет структуру каталогов, чтобы не рисковать текущими данными.
- Для роли MASTER ZONE действует иерархия ролей Discord: даже при выключенной Python-программе токен Cloudflare может работать, но Discord должен разрешить боту выдавать нужную роль.
