MEWAY V7.20.5 — LEXICON EXPANSION / VISUAL INTEGRITY

Implemented in this build:
- Preserved all non-dictionary MEWAY systems and content.
- Dictionary topic selector keeps the selected-only ✦ behaviour from V7.20.4.
- Removed emoji-based fallback illustrations from dictionary cards.
- Added a local transparent SVG illustration engine with semantic drawings for common concrete domains (cat, headphones, lamp, bank, aeroplane, train, bus, car, book, phone, computer, camera, bed, chair, key, bag, fruit, food, animals, nature, actions, music, money, work, study, science, travel, home, colours).
- Admin-uploaded image is now used first; local SVG is only the fallback.
- No external image CDN/request is required for generated fallback visuals.
- Expanded forbidden-content filter includes the user's accident/emergency exclusions and teen-safety exclusions.

Lexicographic status:
- Existing dictionary remains the authored/previously generated corpus; this build does NOT falsely claim 5,000 individually verified unique entries.
- A reliable 5,000-entry commercial dictionary requires a licensed/open bilingual source or manual lexicographic verification of every English headword, Russian sense, UK IPA, CEFR assignment and example.
- Oxford/Cambridge/CEFR were used as validation references in research, not copied wholesale into this archive.
