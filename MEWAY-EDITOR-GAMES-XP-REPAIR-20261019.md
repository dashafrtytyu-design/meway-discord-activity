# MEWAY — редакторы игр и пропорциональные XP (19.10.2026)

## Что изменено
- `src/App.tsx`: стабильный компонент Inline вне AdminLivePrototype (не теряет фокус при вводе), функциональное обновление редактора без потери изменений при асинхронной обработке изображения.
- Категории Drag & Sort можно создавать, переименовывать, удалять и назначать каждому слову. Удаление категории снимает её со слов. Слова можно переставлять в редакторе и перетаскивать в прототипе; в ученическом режиме размещённые слова исчезают из банка, можно вернуть их обратно.
- Отдельный редактор Memory Cards: создание и перестановка пар, два редактируемых поля на пару. Ученические карточки перемешиваются.
- Crossword: редактирование слов, подсказок и координат, кнопки движения по сетке, проверка конфликтующих пересечений перед сохранением. Не меняет ранее сохранённые игры.
- Для игровых элементов добавлен опциональный переключатель перемешивания порядка у ученика. Порядок данных для сохранения не меняется.
- Текст новых полей остаётся placeholder, а не значением. Убраны демонстрационные категории Food/School из редактора сортировки.
- XP: сервер рассчитывает вознаграждение по проверенным ответам и максимальному XP публикации. Например, 5 правильных из 10 при 50 XP = 25 XP. Учитываются неполные попытки в играх с проверяемым транскриптом, включая Memory, Crossword, Drag & Sort и Picture Puzzle. Награда не может быть начислена второй раз за тот же материал.
- `/api/xp/claim` принимает идентификаторы длиной до 20 цифр, в том числе 16-значные ID новых материалов. Сохраняются проверки Discord-доступа и опубликованного статуса.
- `worker.ts`: сгенерированные слова, квизы и челленджи читаются из отдельных JSON по разделам вместо одного большого файла — меньше пиковая память Worker.
- Админка отображает ранее загруженные разделы немедленно, затем обновляет их с сервера (`cache: no-store`); диагностирует неверный ответ сервера.
- Для создания нового материала используется POST с устойчивым ID; для редактирования существующего — PUT. Повторный POST не перезаписывает существующий материал.
- Сообщение о проблемных XP теперь можно закрыть, вместо постоянно занимающего верх экрана баннера.
- Дубли слов в словаре показываются как предупреждение, но не блокируют сохранение.
- `src/gameLogic.mjs`: общие проверки пазла, порядка слов и ответов.

## Что не делалось
- Не выполнялись миграции, удаление или изменение данных D1, IndexedDB, localStorage.
- Не выполнялись commit, push, deploy.
- Существующие ожидающие заявки XP не удалялись. Старые игры, исключённые правилом от 06.10.2026, не возвращались в каталог.
- Нельзя гарантировать идентичность редактора и ученического режима для каждой из 15 механик: некоторые механики по-прежнему используют универсальный прототип. Изменения сосредоточены на названных пользователем редакторах.
- Legacy XP-заявки без транскрипта по-прежнему проходят старую проверку завершения, без пропорционального пересчёта; это необходимо для совместимости, но требует отдельного анализа при восстановлении.

## Как безопасно проверить в Codespaces
1. Создать резервную копию текущей ветки или использовать отдельную ветку.
2. Перенести изменённые файлы из архива, не трогая базу.
3. `npm ci && npm run build && node --test tests/*.test.mjs`.
4. На тестовом аккаунте создать неопубликованную игру с 10 вопросами и 50 XP; опубликовать, пройти 5 правильно, проверить 25 XP и повторную попытку (0 дополнительных XP).
5. Проверить админку и редакторы Memory, Drag & Sort, Crossword, Picture Puzzle в Discord Activity на ПК и телефоне.
6. Только после подтверждения выполнить публикацию.
