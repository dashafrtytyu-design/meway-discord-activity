# Восстановление ваших A1 карточек

Эта версия не восстанавливает данные, которых нет в архиве: ваши пользовательские карточки могут находиться только в Cloudflare D1 или ранее сохранённом экспорте.

Исправлено: при ошибке загрузки публичных материалов приложение больше не подставляет демонстрационный curriculum-content.json как будто это реальные данные. Показывает ошибку и кнопку повтора. Существующий IndexedDB кеш сохраняется.

Не удаляйте D1, не запускайте очистку/импорт поверх рабочей базы. В Cloudflare D1 проверьте SELECT id,section,updated_at FROM content WHERE section='words' ORDER BY updated_at DESC LIMIT 30; и затем откройте /api/content?section=words в авторизованном приложении. Если записей нет, нужен прежний JSON-экспорт базы.

Ни одна запись D1 не изменяется этой сборкой.
