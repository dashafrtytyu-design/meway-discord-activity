# MEWAY: локальная оптимизация Cloudflare (14.10.2026)

## Изменено
- `src/App.tsx`: версия интерфейса больше не заставляет повторно скачивать целые разделы слов/игр/квизов/челленджей и миссий. Изменения проверяются по серверным ревизиям разделов.
- `src/discord.ts`: обновление только версии интерфейса не инициирует инвалидацию учебных материалов.
- `src/App.tsx`: ошибка загрузки миссий не подменяет их статическим демонстрационным JSON.
- Серверные операции сохранения, проверки прав, XP, версии материалов и D1 не изменялись.

## Запросы (ожидаемые, не измеренные в production)
| Сценарий | Ранее | Теперь |
| --- | --- | --- |
| Открыть раздел из памяти | 0 | 0 |
| Открыть неизменённый раздел из IndexedDB после изменения UI-версии | 1 GET /api/content | 0 |
| Открыть неизменённые миссии после изменения UI-версии | 1 GET /api/missions | 0 |
| Изменить только UI-версию на старте | 1 GET /api/content-signal (без повторного скачивания) | 1 GET /api/content-signal (без повторного скачивания) |
| Изменение ревизии раздела | 1 GET /api/sync | 1 GET /api/sync |
| Сохранение карточки | 1 POST/PUT | 1 POST/PUT |

Сигнальные запросы при повторном входе сохранены: они необходимы для обновления серверных ролей/прогресса. Нет нового polling.

## Ограничения
- Невозможно доказать точное количество D1/KV операций без тестового Worker и аналитики Cloudflare.
- Весь поток XP, офлайн-повторы, конфликтные записи и все редакторы требуют отдельного интеграционного тестирования.
- Рабочая D1 не затрагивалась.
- Нельзя считать массовую загрузку тысяч фотографий проверенной до теста на отдельной D1.
