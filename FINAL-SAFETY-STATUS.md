# MEWAY — статус защиты, 14 октября 2026

## Исправлено в исходном коде
- Админ-списки получают `_serverVersion` из `updated_at` D1 для записей, реально находящихся в D1.
- PUT/DELETE карточек и миссий требуют `If-Unmodified-Since-MEWAY`; отсутствие версии — HTTP 428, устаревшая версия — HTTP 409.
- SQL обновления и удаления включает `WHERE id=? AND updated_at=?`, предотвращая перезапись чужого изменения; история сохраняется в той же D1 batch-операции.
- Клиент передаёт версию при редактировании и удалении, не записывая служебное поле `_serverVersion` внутрь JSON карточки.
- Никаких новых фоновых запросов, polling, миграций или операций с рабочей D1.

## Оставшиеся риски и ограничения
- Реальная Cloudflare D1 и Discord в этой среде недоступны; интеграционные проверки и проверка восстановления не выполнены.
- Массовый потоковый экспорт и импорт больших баз НЕ реализованы. Существующий JSON-экспорт может упираться в лимит ответа Worker и объём памяти браузера.
- Production build НЕ подтверждён: npm зависимости недоступны для установки в текущей среде.
- Версия отсутствует у встроенных/сгенерированных материалов, которых нет в D1: их редактирование/удаление теперь требует отдельной операции создания пользовательской копии; слепая запись запрещена.
- Данные фото пока в Data URL внутри D1; R2 не подключён. Для тысяч фотографий требуется отдельный проект миграции с резервной копией.
- Не подтверждены все визуальные сценарии редакторов и восстановление после очистки кеша.

## Обязательные проверки на Cloudflare (только тестовая D1)
1. Экспортировать и сохранить копию production D1 через Cloudflare dashboard/CLI, не выполнять миграций production.
2. Создать отдельную тестовую D1 и отдельный тестовый Worker с собственным binding DB.
3. Создать карточку с фото, сохранить, открыть заново, сверить JSON в D1; выйти из Discord, очистить кеш, войти, проверить изображение.
4. Открыть карточку в двух админ-вкладках. Сохранить в первой, затем попробовать сохранить из второй: ожидается 409, первая версия остаётся в D1.
5. Аналогично проверить DELETE из устаревшей вкладки (409), миссии, квизы, игры, челленджи и слова A1–C2.
6. Выполнить экспорт, восстановить только в пустую тестовую D1 и сверить количество записей и изображения; при больших объёмах не использовать один браузерный JSON как единственную резервную копию.
7. Проверить Cloudflare Analytics, ошибки Worker и счётчики D1 после тестов.

**Не рекомендовано массовое заполнение до реальных интеграционных проверок.**
