# MEWAY — исправление повторного входа администратора

Исправлено: сохранённая роль из IndexedDB больше не используется при неуспешной проверке /api/progress-signal. Клиент переходит к стандартной Discord OAuth авторизации. При успешной проверке роль синхронизируется с Worker. Worker сравнивает Discord User ID с ADMIN_DISCORD_ID после trim().

Проверка после публикации: войти в Discord Activity под своим аккаунтом, убедиться в появлении вкладки «Админ», закрыть и снова открыть Activity, повторить. Если вкладки нет, проверить правильность переменной ADMIN_DISCORD_ID в том же Worker и то, что ответ /api/auth/discord содержит role=admin. Не отправлять токены или секреты.
