MEWAY V7.20.0 — VISUAL DICTIONARY + CONTENT INVENTORY

Changes from V7.19.9:
1. Preserved topic picker, CEFR filters, XP progression, offline-first cache, delta sync, admin/student separation and existing design.
2. Added an automatic local visual to every dictionary card. Existing admin-uploaded images always have priority.
3. Concrete vocabulary receives a matching local pictogram (e.g. aeroplane/airport -> plane, burger -> burger, train -> train, fruit -> matching fruit where available).
4. Abstract vocabulary receives a topic-semantic visual instead of a broken/empty image.
5. Visuals are generated locally as inline SVG data URIs; they do not call an image CDN, do not create a Cloudflare request per image, and require no recurring download.
6. Added lazy image rendering in dictionary cards.
7. Image-guess games can use the same local visual fallback when an explicit admin image is absent.
8. Picture-puzzle games can use the same local visual fallback when an explicit admin image is absent.
9. Admin can still upload/replace a real image; an uploaded image overrides the automatic visual.
10. Added MEWAY-V7.20.0-CONTENT-INVENTORY.txt with exact generated counts and per-category counts.

Validation:
- App.tsx TypeScript transpile syntax diagnostics: 0.
- App.tsx delimiters balanced.
- No external image URL was added for automatic dictionary visuals.
- Existing generated curriculum counts remain unchanged: 2730 content items + 1464 missions.
- Dictionary: 192 collections, 1437 word-card occurrences, 1333 unique English entries.

Note:
A web application cannot make displayed learning content absolutely impossible to inspect. These visuals are optimized for speed and zero per-image network calls, not DRM.
