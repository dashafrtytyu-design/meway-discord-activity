# Защита восстановления из истории

POST /api/admin/content-history/:id требует заголовок `If-Unmodified-Since-MEWAY` с `_serverVersion` текущей записи. Без версии: 428; при устаревшей версии: 409; если запись отсутствует: 404 (без опасного upsert). Предыдущая версия сохраняется в `content_history` до условного `UPDATE ... WHERE updated_at=?` в одной D1 batch-транзакции. Ответ возвращает новую `_serverVersion`.

Восстановление удалённого материала из истории намеренно не выполняется этим обработчиком: для него нужен отдельный сценарий с проверкой tombstone и отсутствия ID. Рабочая D1 не затрагивалась.

Тесты на этом этапе статические/локальные. Для подтверждения гонки на Cloudflare требуется тестовая D1: открыть один материал в двух вкладках, восстановить из истории в первой, попытаться восстановить со старой версией во второй (ожидается 409); затем проверить историю и фото в D1.
