MEWAY V7.21.3 — PUZZLE + CROSSWORD QA

Scope: based on V7.21.2 MAX CLOUD SAVER. No XP/role/Admin/Cloud Saver architecture changes.

PICTURE PUZZLES
- Fixed universal blank-tile rendering: puzzle tiles now render the actual word image with an <img> crop rather than CSS background-image.
- Applies to every picture-puzzle item and to local SVG/data-URI visuals, static images and admin-provided images.
- 36 picture-puzzle games remain: 6 per CEFR level A1–C2.

CROSSWORDS
- Rebuilt placements for all 36 crossword games (6 per A1/A2/B1/B2/C1/C2).
- 216 crossword answer/clue pairs audited structurally.
- Every answer is normalized to A–Z cells; cell count is derived from the normalized answer itself.
- Collision validator result: 0 conflicting-letter cells.
- Empty-answer validator: 0.
- Missing-clue validator: 0.
- Crossword EN/RU pairs compared with the same entries in the MEWAY dictionary corpus: 0 translation mismatches where a dictionary reference exists.
- Fixed a renderer bug where row=0 was incorrectly treated as missing because of `Number(row) || fallback`; zero coordinates are now preserved.
