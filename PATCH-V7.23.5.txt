MEWAY V7.23.5 — INTERACTION PARITY + PLACEMENT HOME + LOCAL LEADERBOARD AVATARS

1. A1–C2 level selectors are always selectable on Missions, even when access is locked.
   Access is checked only when opening the actual material. Locked users can inspect level/category structure.
2. Home CTA now trusts the authenticated server placementCompleted flag, not a generic browser key.
   The ordinary Mission/Game buttons return only after the first Placement result is successfully saved.
3. On phones (<=600px), the three quick topic/game buttons are hidden. The category/topic picker remains.
   Tablet/desktop quick topics are unchanged.
4. Leaderboard rows now include the participant's saved MEWAY avatar from the same existing D1 progress query.
   The complete leaderboard (including avatar data) is cached in encrypted IndexedDB via the existing cache layer,
   so repeat views can render locally before/without another D1 read.
5. No polling was added. Level/category switching remains entirely local after section content is loaded.
