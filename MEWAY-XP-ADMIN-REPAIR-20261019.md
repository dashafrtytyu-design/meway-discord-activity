# MEWAY: безопасная правка XP, кэша и диагностики админ-панели

## Изменения
- `src/xpQueueRunner.ts`: одна ошибочная заявка (404/422) не блокирует остальные. Ошибочная заявка остаётся в IndexedDB и localStorage для проверки. При сбоях сети, 401/403/429/5xx очередь останавливается без удаления. Подтверждение удаления происходит только после успешного ответа с `progress`.
- `src/App.tsx`: использует новый обработчик очереди, не изменяя серверные проверки XP. Проблемные ID и статусы выводятся в консоль без токенов доступа.
- `src/App.tsx`: при изменении ревизии контента получает полный актуальный снимок раздела. Старый кэш сохраняется при сетевом сбое; никаких глобальных очисток хранилищ.
- `src/App.tsx`: ошибки загрузки `/api/admin/bootstrap` и `/api/admin/content` показывают HTTP-статус и безопасный текст ответа.
- Добавлены тесты `tests/xp-queue-runtime.test.mjs` для 404, 422, сети, 503 и подтверждения.

## Ограничения
- Правки внесены только в исходники распакованного ZIP. D1, Cloudflare и аккаунты не затронуты.
- Серверные правила скрытия игр до 2026-10-06 сохранены. Их неподтверждённые заявки остаются ожидающими проверки.
- Проверка реальной админ-панели требует авторизованной сессии и логов Cloudflare: из локального архива нельзя доказать устранение причины серверной ошибки.
- Полная сборка не выполнена: установка npm-пакетов в этой среде не завершилась. Синтаксис изменённых TypeScript-файлов проверен; тесты запущены.
- В исходном архиве уже были 18 падающих тестов; после правок также 18. Новых падений нет, 5 новых тестов проходят.

## Безопасная проверка перед деплоем
1. Сохранить резервную копию D1 средствами Cloudflare.
2. `npm ci && npm run build && node --test tests/*.test.mjs`
3. Проверить авторизованный вход админа, загрузку каждого раздела и очередь XP на тестовом аккаунте.
4. Только после этого выполнять ручной deploy.
