MEWAY V7.7 — Interactive Game Studio

Added without changing the existing Worker API/D1 schema:
1. Crossword Lab — editable English answers, clues, row, column, direction.
2. Picture Puzzle — admin-controlled image/word and 2x2–5x5 grid; drag swap on desktop, tap-swap on touch devices.
3. Drag & Sort — admin-defined words and categories; drag/tap words into category zones.

Admin control:
- Existing title, description, category, level, icon, XP, status controls remain.
- Game items remain editable from the existing Games builder.
- Crossword placement is controlled per word by row/column/direction.
- Puzzle image comes from the first game card and can be replaced from the existing image uploader; grid size is editable.
- Drag & Sort groups come from each card's Category field.

Cloud saver:
- No polling was added.
- No new API endpoint was added.
- Playing/moving puzzle pieces, crossword typing, dragging and sorting are entirely client-side and make zero Cloud/D1 requests.
- Existing progress batching remains unchanged; normal completion/progress sync uses the existing batched flow.
- Game content is loaded through the existing session cache.

Themes/responsiveness:
- Added dedicated light/dark styling for all three games.
- Added responsive layouts for desktop/tablet/mobile.

Build note:
- Source syntax errors introduced during editing were corrected. The sandbox package install was unavailable/incomplete, so a full npm build could not be re-run here because local vite/node type packages were missing. Run npm install/npm ci in StackBlitz and npm run build before deployment.
