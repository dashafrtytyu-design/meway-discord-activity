# MEWAY — исправление загрузки материалов (15 октября 2026)

Изменения только в `src/App.tsx`:

- Увеличен ограниченный тайм-аут загрузки списка административных материалов с 20 до 60 секунд, включая запрос следующих страниц. Большие JSON с фотографиями могут обрабатываться дольше 20 секунд. Это **не ускоряет сервер** и не гарантирует успешную загрузку.
- Отменённый по тайм-ауту запрос теперь показывает понятное сообщение вместо технического `The user aborted a request`.
- Когда ранее загруженные записи уже отображаются, сообщение о сбое обновления является ненавязчивым статусом, а не тревожным красным уведомлением.
- Существующий IndexedDB-кеш, постраничная загрузка по 6 записей и серверное подтверждение сохранения сохранены без изменений.
- Рабочая Cloudflare D1 не изменялась, миграции не запускались, дополнительные фоновые запросы не добавлялись.

## Ограничения

Пока **нет** доказательства, что все карточки есть в D1 или что текущая серверная проблема устранена. При первом входе без кеша приложению всё ещё необходим ответ сервера. Для диагностики требуются Network Response/Timing и проверка D1. Production build необходимо выполнить после установки зависимостей.
