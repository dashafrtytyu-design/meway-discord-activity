# MEWAY — исправление обновлений учебного контента

- Убрано часовое браузерное/edge-кеширование `/api/content-signal` и `/api/manifest`, из-за которого новые карточки, игры, изображения и правки оставались невидимыми ученикам.
- При следующем запуске Activity один лёгкий запрос читает ревизии D1; разделы загружаются из локального кеша, а изменённые разделы обновляются через `/api/sync`.
- В редакторе теперь различаются «Опубликовано» и «Черновик»: черновики не видны ученикам.
- Фото карточек хранятся в данных материала как data URL. Для больших фото возможны ограничения размера записи/запроса; их загрузка в отдельное хранилище R2 здесь не реализована.
- Подтверждённые XP, доступы, локальный Ассистент и дизайн не изменялись.
- Проверка на реальном Cloudflare и разных устройствах требуется.
